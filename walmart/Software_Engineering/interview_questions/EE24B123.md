# Interview Questions
**Company:** Walmart
**Profile:** Software Engineering

Interview had 2 rounds, first one was technical, for first 30 minutes he asked me about my resume projects, later he asked to write pseudocode for 2 easy coding questions, one of them was like given an array containing elements from 1 to n not in any order, but one number is missing how do you find the missing number, i gave the n(n+1)/2 - array sum approach he told correct and u can use xor also, another one was like a string question, they will give 3 strings, in str1 we have to find where str2 occurs and replace it with str3, the key is to handle indexes properly as str2 and str3 could have different lengths, then he asked to explain about oop and then asked a specific question on inheritance like the virtual function, like he will give a code with a base class and derived class and ask what will be printed which is basic OOP only, then he asked dbms, actually I learnt to write only sql queries so I haven't prepared for those but somehow i thought of some approach and explained my thought process, the question was like if there are millions of records in the database how do you search through it for a particular id 

Then in round 2, my interviewer was from electrical background so he asked me a bit on that, he gave me one very easy coding question on array and then one more question to find min, max element in array, just after i finished writing my pseudo code he screamed tell me kirchoff 2nd law, and then he said i was just trying to divert your mind from coding, later, since my resume was more ai oriented he told to write down 4 ways how you would use ai in electrical domain, next question he asked how would you use ai in a electrical power station.
