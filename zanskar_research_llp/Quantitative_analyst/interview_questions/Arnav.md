# Interview Questions
**Company:** Zanskar Research LLP
**Profile:** Quantitative Analyst

**Result:** Rejected.

**Interview 1** - Started with one of the projects on my resume.

- A, B and C are standing in a line, each wearing a hat which may be white or
  black. A can see B and C, B can see C, and C can't see anyone. The goal of the
  game is for a person to guess their own hat colour. Guessing starts from A, then
  B, then C. If at any point one of them gets it wrong then they lose; if someone
  gets it right then all of them win. On a person's turn they can choose either to
  guess or to skip. They can strategise before the hats are assigned. Using an
  optimal strategy, what is the probability that they win?
- If P is a prime > 3, prove that P^2 - 1 is divisible by 24.
- Given a chessboard with one square poisoned, find the minimum number of queries
  in which we can find the poisoned square. In each query you can choose a set of
  squares and you will be told whether the poisoned square is in that set or not.
- A standard Bayes theorem disease-and-test question.
