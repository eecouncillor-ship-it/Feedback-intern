# Interview Questions
**Company:** Pluswealth Capital Management LLP
**Profile:** Quantitative Research

**Result:** Rejected.

**Interview 1**
- Given an n x m matrix with the property that each entry is equal to the average
  of its orthogonal neighbours, prove that all elements must be equal.
- We roll a fair die till we get a 6. Given that we get only even numbers, find the
  expected number of rolls.
- 1-2 more probability questions / puzzles.

**Interview 2**
- Basic C++: `static` and `const int`, size of a class, etc.
- Given a polynomial of unknown degree with positive integral coefficients, you can
  query the value of the function at any value. What is the minimum number of
  queries needed to find all the coefficients?
- You start at the origin with p(+1) = 0.6 and p(-1) = 0.4. Find the expected
  number of steps to reach N. What if p = 0.5?
- 10 pairs of numbered gloves - make pairs of gloves such that the difference
  between the numbers on the gloves in each pair is at most one.
