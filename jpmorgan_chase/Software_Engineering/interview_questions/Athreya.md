# Interview Questions
**Company:** JPMorgan Chase
**Profile:** Software Engineering

**Result:** Accepted.

Three rounds - two technical and one HR.

**Technical 1**
Two basic DSA questions. The first was Number of Islands (LeetCode), the second
was similar to Rotting Oranges (LeetCode). Was asked to code on pen and paper.

**Technical 2**
Two questions again. The first was an implementation of an LRU cache. The second:
you have a list of ranges `[l, r]`, each corresponding to a balloon stretching from
l to r (both included). If you shoot an arrow at coordinate x, all balloons passing
through x will pop. Find the minimum number of arrows needed to pop everything.

**HR**
Some nonsense questions, I don't even know what happened. I gave personal examples
and got rejected - later they called me and gave me the offer.
