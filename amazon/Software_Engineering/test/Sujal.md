**Profile:** Software Engineering

1. A DP question with a timer of 30 minutes.
2. An AI-assisted coding question (C++) where you have to find bugs in code given
   some sample tests. 1.5 hours for that. The AI would never tell you the direct
   solution but will give you the traceback of the errors so you can go there and
   fix the bugs. If you don't know C++ you can ask it for syntax and it will tell
   you properly.

fail this.
