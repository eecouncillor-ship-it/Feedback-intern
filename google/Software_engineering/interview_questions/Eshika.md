# Interview Questions
**Company:** Google
**Profile:** Software Engineering

**Result:** Received offer (off-campus).

If you perform well in Google's Big Code competition, HR will reach out to you for
an initial vibe check and schedule 2 technical interview rounds for the
internship - before the campus internship drive.

- Question 1: Number of Visible People in a Queue (LeetCode). Part 1 was to
  compute the answer for only the last person; part 2 was the LeetCode question.
- Question 2: Count String Prefixes on Tree Paths (LeetCode 137 in their list).
