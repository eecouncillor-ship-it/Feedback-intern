# Test Questions
**Company:** AlphaGrep Securities
**Profile:** Quantitative Trading

4 questions, all coding, C++ only. Python was allowed for one of them.

**Q1:** Given an array of integers and an integer G, maximise the quantity
`G * (number of split arrays) - (sum over the maximum element in each split
array)`, such that all the splits are non-empty. Example: `[4, 1, 1, 4]` with
G = 3 - the optimal split is `[4, 1, 1, 4]` itself.
