2 DSA questions.
1. Pretty easy greedy implementation (will hardly take 15 minutes).
2. Much tougher, involving DP on trees: there is an n-node tree with n-1 edges,
   each edge has some weight. You have to remove some edges such that the total
   weight of all the remaining edges is maximum, and remove edges in such a way
   that the degree of every node of the tree is always <= k. Given the input tree
   and k, output the sum of the weights of all remaining edges.
