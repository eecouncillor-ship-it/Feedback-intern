# Interview Questions
**Company:** Texas Instruments
**Profile:** Digital

1) What are universal gates?
2) How do you construct a NOT Gate using NAND gates?
3) Could a 2x1 Multiplexer be considered as an universal gate?
4) How to implement a NAND gate using 2x1 Multiplexer?
5) How to implement a 4 input NAND gate using 2 input NAND gates?
6) How to implement 5 to 1 MUX using 2 to 1 MUX's?
7) How to implement 6 to 1 MUX using 2 to 1 MUX's?
8) To implement a n to 1 MUX, how many 2 to 1 MUX do you need?
9) For an n to 1 MUX, how many select lines are required?
10) Construct a circuit that detects a 0 to 1 transition and remains 1 for 1 clock cycle?
11) Construct a circuit that detects any transition in the input signal and outputs 1 for 1 clock cycle?
12) Given an input clock of frequency f, could you make a clock of frequency f/3 and duty cycle 33.33%?
13) Given an input clock of frequency f, could you make a clock of frequency f/3 and duty cycle 50%? If you had come with a solution using 4 or more Flip Flops could you come up with a solution using less number of Flip Flops?
14) Let an n to 1 MUX be implemented using 2 to 1 MUX's, if each 2 to 1 MUX has a propagation delay of T, what would be the worst case propagation delay of n to 1 MUX?
15) Given an input clock of frequency f, could you make a clock of frequency f/3 and duty cycle 33.33% only using dff's and no ther gates?
16) How do you delay an incoming signal by 1 clock cycle?
17) How do you delay an incoming signal by 1/2 clock cycle?
18) How to construct an inverter using XOR gate?
19) How to construct AND gate using XOR gate, is it possible?
20) How to implement a D-Latch using 2 to 1 MUX?
