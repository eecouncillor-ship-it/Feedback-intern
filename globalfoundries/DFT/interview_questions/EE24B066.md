# Interview Questions
**Company:** Globalfoundries
**Profile:** DFT

1st interview:
-Explain how a microprocessor works. The diagram was on the screen and the use of each component was to be explained.
-What is the type of external memory closest to microprocessor? Draw diagram of one cell of SRAM memory.
-Explain setup time and hold time. Why are they needed (explanation using MOSFET characteristics)
-Write verilog code for a d-latch. Miscellaneous questions on the code like blocking vs non-blocking assignment, why is enable signal required etc.
-What are Universal gates?
-What are the requirements for a memory element?
-Explain the difference between synchronous and asynchronous systems.

2nd interview:
-Explain the difference between HDL and regular languages(like C).
-Write code for an n-bit counter in verilog.
