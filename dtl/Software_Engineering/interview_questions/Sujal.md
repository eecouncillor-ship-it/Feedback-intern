# Interview Questions
**Company:** DTL
**Profile:** Software Engineering

**Result:** Rejected. 2 rounds.

**Round 1 (45 min)**
- Difference between Python and C++.
- A lot of resume/project questions.
- Implement the `std::vector` class on Google Docs with no IDE, handling all edge
  cases.

**Round 2 (3+ hours in one sitting)**
Every CS topic you can possibly think of: OS, computer networks, DBMS, hashmaps and
collisions, multithreading, smart pointers, unique pointers, 2 DSA questions, 1
implementation question in C++, relational databases, B-trees, Linux/bash, and
questions about different data structures.

I don't remember every question now, but they involved knowing the basics of all
topics and the advanced parts of some. Given some hints you would be able to solve
them provided you have enough dev knowledge. (The interviewer was from South East
Asia, which made it difficult for me to understand what he was saying, but he wrote
down all the questions.)
