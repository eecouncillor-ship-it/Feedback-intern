# Interview Questions
**Company:** Goldman Sachs
**Profile:** Software Engineering

3 rounds. Goldman Sachs has 3 sub-verticals (at least in the software part), so you
will have an interview with one person from each of these verticals. They are all at
the same level - a basic DSA question and HR questions.

**Interview 1**
- A lot about my resume, and why I am applying for an SWE role being from DA.
- He wanted me to design a verification system to make sure the number of fraud
  users goes down without reducing customer satisfaction. It was a very abstract
  question - it just tested edge case detection in a particular situation, and I had
  to write pseudocode for part of it. Because it was so abstract it was very
  important to interact a lot with the interviewer and make the necessary
  assumptions.

**Interview 2**
- More focused on a DSA array question: how many minimum operations do you need to
  reduce a positive array to all zeroes, where in each operation you can decrease a
  subarray by 1?
- A couple of HR questions too, mainly to gauge whether I would be interested in
  this job or not.

**Interview 3**
- A question centred around hashmaps. She kept changing it up, bringing in new
  situations and updates. You had to adapt to the question and even change the data
  structures used, while keeping track of the edge cases.
