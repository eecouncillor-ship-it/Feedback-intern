# Test Questions
**Company:** Goldman Sachs
**Profile:** Software Engineering

An online test covering about 3 DSA questions, C++ basics and some probability
questions. The questions weren't too hard - one was based on topological sorting
and one was a simple array question (I don't remember the last one, but it was of a
similar level).

It's fine even if all of your test cases for the coding questions don't pass. It's
important to maximise your score as much as possible, so don't waste your time
fretting about something you weren't able to finish perfectly.
