# Internship Feedback - EE24 Batch

Interview, test and group-discussion feedback from the internship drive, collected by company and profile.

## Layout

```
<company>/<Profile>/test/                 <- online test / OA
<company>/<Profile>/GD/                   <- group discussion
<company>/<Profile>/interview_questions/  <- interview rounds
```

Each file is one contributor - named by roll number where available, otherwise by name - and starts with the same three-line header:

```markdown
# Interview Questions
**Company:** Texas Instruments
**Profile:** Analog
```

See [RESOURCES.md](RESOURCES.md) for preparation material.

1. Use the existing company folder if there is one - check for spelling variants before creating a new one.
2. Use the existing profile folder if the role matches; profile folders are `Title_Case_With_Underscores` and do not carry an `Intern` suffix.
3. Name your file after your roll number, e.g. `EE24B054.md`.
4. Keep the three-line header above the body.
