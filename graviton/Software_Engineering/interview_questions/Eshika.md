# Interview Questions

**Profile:** Software Engineering

**Result:** Rejected.

**Interview 1** - No DSA questions.

The main focus was C++ theory:
- What is the size of a class with only regular (non-virtual) functions?
- `const` pointer vs pointer to `const`.
- Size of `char` vs `int`, and some pointer arithmetic.
- Virtual functions.
- lvalue vs rvalue references; move vs copy and when is one more efficient than
  the other.
- How is `std::list` implemented, and what are the benefits of `std::vector` over
  `std::list`? (Mention caching.)
- Runtime vs compile time polymorphism, and what causes one to be better than the
  other.
- Difference between `static` and `const`, and where each is stored in memory.

Also some puzzles. No probability questions.
