# Test Questions
**Company:** Gödel Machines
**Profile:** Software Engineering

5 questions. Online, we were assigned a Jupyter notebook with 5 problems -
implement them and pass the test cases.

The 1st problem carried the most marks and was about writing a pipeline to chunk
speech, convert it to text, send it to an LLM, get a response, chunk it, convert it
to speech and join it using the PyDub library.

The rest were typical DSA-easy questions involving implementation / debugging /
refactoring code - things a dev does.
