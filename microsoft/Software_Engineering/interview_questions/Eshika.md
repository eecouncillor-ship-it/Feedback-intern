# Interview Questions
**Company:** Microsoft
**Profile:** Software Engineering

**Result:** Received offer.

**Interview 1**
- Basic strings question: given numbers represented as strings, find which one is
  smaller without converting them to integers.
  - Follow up 1: what if there were leading or trailing zeroes?
  - Follow up 2: what if the numbers could be negative?
  - Follow up 3: what if the numbers could have a +/- sign? (Very important to
    think of the +0, -0, 0 edge case here.)
- Create test cases which cover all scenarios.
- Explain a project on your resume.

**Interview 2** - System design + coding
- Design a recommendation engine (e.g. for a retail service) and mention the data
  required and how to store it (SQL / NoSQL / vector DB, data structures etc.).
- Give a high level description of what the process looks like to fetch
  recommendations given one product (talk about RAG, cosine similarity, ranking
  and re-ranking, smart chunking etc.).
- Code to compute cosine similarity between 2 encodings, and explain the intuition
  behind why cosine similarity works (talk about directions encoding meaning).
